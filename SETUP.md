# Setup (5 min)

1. Repo name must equal GitHub username: `vaibhavisharnagat/vaibhavisharnagat` (public).
2. Copy everything in this folder to repo root (`README.md`, `assets/`, `.github/`).
3. Repo → Settings → Actions → General → Workflow permissions → **Read and write**.
4. Actions tab → run **GitHub-Profile-3D-Contrib** once (makes `profile-3d-contrib/*.svg`).
5. Actions tab → run **Generate Snake Animation** once (makes `output` branch).
6. Edit: email in Find Me, Kaggle / HuggingFace handles, "Currently Shipping" table.
7. Edit LeetCode numbers: `assets/leetcode.svg` is a snapshot (66 solved, 28/35/3). Regenerate: edit `gen.py` values, run `python3 gen.py`.
